# Combustible · Luz

PWA para consultar de forma rápida el precio horario de la electricidad (PVPC) y precios de combustible en Gijón.

## Funciones
- Precio de la luz ahora
- Hora más barata
- Top 3 de horas
- Listado horario y ranking por precio
- EasyGas Roces: Gasolina 95, Gasolina 98 y Gasóleo A
- Estación más barata de Gijón por combustible
- Instalable como PWA en móvil, tablet y ordenador

Los datos se obtienen mediante una función serverless en `/api/dashboard` y se cachean durante 5 minutos.
